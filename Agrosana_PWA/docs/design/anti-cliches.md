# Clichés prohibidos en AgroSana

Si una opción o una pantalla incluye alguno, se sustituye por la alternativa antes de aprobarla.

| Cliché | Alternativa en este proyecto |
|---|---|
| Lorem ipsum, cifras, testimonios o logos inventados | Solo contenido real (spec 003, etiquetas de los productos); datos de contacto marcados como de ejemplo |
| Gradiente morado-rosa de plantilla | Gradientes dentro de la paleta del proyecto, o ninguno |
| Componentes sin personalizar (aspecto de plantilla) | Tokens propios aplicados a cada componente |
| Estado vacío en blanco o solo "No hay datos" | Estado vacío que explica qué falta y ofrece la acción |
| Error sin salida ("Algo salió mal") | Qué pasó, que no se perdió nada y cómo reintentar |
| Animaciones en todo sin jerarquía | Un momento protagonista por pantalla; el resto sobrio |
| Estado transmitido solo por color | Color + texto o icono con nombre accesible (la categoría siempre escrita) |
| Tríada de tarjetas icono + título + texto para presentar la empresa o las ventajas | Una forma propia de la idea: texto corrido, una pieza destacada o datos reales. **Excepción:** Nosotros conserva sus 3 tarjetas por la spec 003 CA7 (decisión del usuario, 2026-10-09); no pueden ser idénticas ni de plantilla |
| Fuente del sistema como tipografía de marca | Familia elegida e incrustada desde `act2/` |
| Mismo esqueleto con otra piel en cada opción | Composición distinta de la pantalla principal |
| Hero genérico con ilustración stock y "Bienvenido a X" | La tarea principal del usuario visible desde el inicio |
| Grid de cards idénticas sin jerarquía | Elemento destacado y variaciones de tamaño |
| Mezcla verde/azul de la plantilla de la práctica guiada | Solo la paleta de la opción |
| Opción sobria sin nada que se recuerde (rondas 1 y 2) | Un elemento audaz y reconocible por opción |
| **Sector:** fotos stock de manos con brotes o tractores | Las fotos reales de las etiquetas y material propio |
| **Sector:** verde chillón y hojas decorativas | Verdes profundos de la marca; ninguna hoja como adorno |
| **Sector:** moléculas y gotas "científicas" como adorno | Datos reales del producto (composición, categoría) como elemento gráfico |
| **Sector:** agricultor estereotipado como imagen de marca | Sin personas genéricas; el protagonista es el producto y su uso |
